Express Locker Backend

Parcel locker backend for logistics practice.

This Spring Boot service models the core flows behind an express locker system: users, cabinets, cabinet doors, storage orders, send orders, pickup codes, and admin operations. It is meant as a readable backend practice repo with clear API structure and verification paths.

Java 8 Spring Boot MyBatis-Plus MySQL Redis

What it covers

  • User login, registration, password updates, and verification.
  • Cabinet management and available door lookup.
  • Storage and send order flows with pickup codes.
  • Mapper-based data access backed by MySQL.

Start here

  • Run mvn test to check the project.
